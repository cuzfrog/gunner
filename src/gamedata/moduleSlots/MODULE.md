# moduleSlots

Module-to-slot mapping generated from EVE Online inventory categories. The public surface is `ModuleSlotCatalog` (exported from `index.ts`) and `StaticModuleSlotCatalog`. The data file `moduleSlots.ts` is generated by `scripts/generate-module-slots.ts` and is marked no-new-exports.
