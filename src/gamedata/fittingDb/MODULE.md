# fittingDb

Fitting database generated from EVE Online SDE via Pyfa staticdata. The public surface is `FittingDbData` (and alias `FittingDb`) and `FITTING_DB` (exported from `index.ts`). The data file `fittingDb.ts` is generated by `scripts/generate-fitting-db.ts` and is marked no-new-exports.
