# fittingDb

Fitting database generated from EVE Online SDE via Pyfa staticdata. The public surface is `FittingDbData` (and alias `FittingDb`) and `FITTING_DB` (exported from `index.ts`). The data file `fittingDb.ts` is generated by `scripts/generate-fitting-db.ts`.

Gate relaxed: `fittingDb.ts` was temporarily removed from `no-new-exports` to add `TargetPainterStats`, `MissileGuidanceComputerStats`, `MissileGuidanceEnhancerStats`, `MissileScriptStats`, and `DroneStats` alongside the existing stat-type family. These types are co-generated with their data tables by the generator script; splitting them into a separate file would fragment the stat model.
