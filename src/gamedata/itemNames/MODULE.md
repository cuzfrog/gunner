# itemNames

Localized item-name packs generated from EVE Online SDE via Pyfa staticdata. The public surface is:

- `ItemNameCatalog` / `StaticItemNameCatalog` / `LazyItemNameCatalog` — forward-only, id -> localized label lookup for UI rendering. `LazyItemNameCatalog` dynamically imports non-English packs.
- `ItemNameLoader` — async preloading interface for lazy catalogs.
- `ItemNameResolver` / `StaticItemNameResolver` / `LazyItemNameResolver` — name -> ids reverse lookup for EFT import boundaries.

The data files `item-names-*.ts` and `item-name-collisions-*.ts` are generated by `scripts/generate-fitting-db.ts` and are marked no-new-exports. The alias file `item-name-aliases-en.ts` is generated by `scripts/generate-item-aliases.ts` from Pyfa conversion tables and is marked no-new-exports.
