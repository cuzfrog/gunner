# itemNames

Localized item-name packs generated from EVE Online SDE via Pyfa staticdata. The public surface is:

- `ItemNameCatalog` / `StaticItemNameCatalog` — forward-only, id -> localized label lookup for UI rendering.
- `ItemNameResolver` / `StaticItemNameResolver` — name -> ids reverse lookup for EFT import boundaries.

The data files `item-names-*.ts` and `item-name-collisions-*.ts` are generated by `scripts/generate-fitting-db.ts` and are marked no-new-exports.
